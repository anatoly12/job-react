# job-reactor

This project is a job tracking application designed to help users manage their job applications throughout the job search process.

## Features
- Track job applications across various stages from interested to offer
- Schedule reminders for follow-ups and interviews
- Record and transcribe interview practice sessions
- Manage job postings with detailed information

## Technologies Used
- React for the frontend
- Redux for state management
- Node.js and Express for the backend
- MongoDB for the database
- Material-UI for React components

## Getting Started
To get started with this project, clone the repository and install the dependencies:

```
git clone https://github.com/your-repository/job-reactor.git
cd job-reactor
npm install
```

To run the application locally:

```
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
